# portfolio-system

Portfolio site of Liudmyla Khlystun, UX/UI Designer and AI UX/UI Engineer, rebuilt on a design system.

- Stack: Next.js (App Router), TypeScript, Tailwind CSS
- Plan and design tokens: [docs/plan.md](docs/plan.md)
- Deploys to Vercel automatically on every push to `main`

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.
